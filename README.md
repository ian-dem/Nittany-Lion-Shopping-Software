# Nittany-Lion-Shopping-Software

## E-Commerce Platform

This project is a prototype e-commerce web platform designed to facilitate transactions between buyers and sellers, featuring separate dashboards, robust user management, and a dedicated backend for order and product handling.

---

## Key Features

### Buyer Experience
* **Buyer Dashboard:** A centralized hub providing access to all key buyer functions.
* **Order Management:** Dedicated **Orders Page** to view current and past purchases.
* **Personalization:** **Recommended Page** for product suggestions.
* **Shopping Cart:** Full **Cart** functionality for managing pre-purchase items.
* **Account Management:** Dedicated **Account** section for profile and settings.

### Seller and Administration
* **Seller Dashboard:** Interface for managing inventory and listings.
* **Product Management:** Tools for **Creating and Managing Product Listings**.
* **Helpdesk Support:** A modal for creating support tickets related to:
    * Business Registration
    * Category Registration
    * General/Technical Issues

### Core Functionality
* **User Authentication:** Complete **Login** and **Registration** flows for all Users.
* **Access Control:** Implemented logic for secure page navigation and user-specific access.
* * **Support Ticket System:** Handling for users to submit requests to support. Systems to allow support to handle request on the front-end.

---

## Technology Stack

* **Backend:** Python, Flask
* **Frontend:** React
* **Database:** SQLite

## Getting Started

Follow these instructions to set up and run the project locally.

### Prerequisites

To run this project, you will need:

* Python 3.9+
* Node.js 18+
* npm


### Python Dependencies
```bash
pip install Flask
pip install flask-cors 
pip install bcrypt
```

### Node.js packages
```bash
react
react-dom
axios
react-router-dom
```
